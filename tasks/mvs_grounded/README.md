names something that has to be found in the structure and gives no residue numbers.

frozen mmCIF with gemmi; the check and its numbers are in each task's
`provenance.checks`. A reference holds only what the prompt states (the grey cartoon is
there because the prompt asks for it).

## How each reference is derived

| template | the request names | reference |
|---|---|---|
| `gr-all-but-chain` | one chain to leave out | Every other polymer chain of the facts; drawn and left-out chains together are the whole polymer. |
| `gr-attachment` | ligand and the residue it is bonded to | Polymer residues with a `covale` record to the named ligand; link re-measured (< 2.0 A). |
| `gr-catalytic` | catalytic residues | UniProt 'Active site' features (frozen), mapped through the frozen SIFTS table; residue identity must match UniProt. |
| `gr-disulfides` | disulfide-bonded cysteines | Both ends of every `disulf` record; S-S re-measured (1.9-2.3 A); no unannotated SG-SG pair within 2.5 A. |
| `gr-entity` | named subunits | Chains of each polymer entity; the prompt's name for an entity must match exactly one entity description. |
| `gr-glyco-sites` | glycosylation sites | Polymer residues covalently bonded to a sugar (`_struct_conn`); bond re-measured; equal to the polymer part of Mol*'s `branched` selection. |
| `gr-heme` | heme | Components the facts flag as heme (an iron porphyrin), every copy; one FE atom per copy confirmed in the mmCIF. |
| `gr-heme-axial` | residues on the heme iron | Polymer residues with a `metalc` record to a heme FE; bond re-measured; neighbour search within 2.6 A agrees. |
| `gr-ligand` | named ligand | The component whose frozen name or synonym (RCSB chemical component record), or the entry title, contains the prompt's name; every copy. |
| `gr-longest-helix` | the longest helix | The helix record with the most observed residues, when it leads by 3 or more. |
| `gr-metal-site` | a metal and its coordinating residues | Every copy of one metal ion, plus the polymer residues with a `metalc` record to it (3 or more per site, none to a symmetry copy); used only if a neighbour search within 2.6 A, with symmetry, finds exactly those residues. |
| `gr-modres` | modified residues | Non-standard residues inside polymer chains (facts), by component; the name is checked against the component record. |
| `gr-nucleic` | the DNA / the RNA | Mol*'s `nucleic` selection, checked to be exactly the DNA or RNA chains of the facts. |
| `gr-secstruct` | helices and strands | `_struct_conf` and `_struct_sheet_range` ranges, re-read from the mmCIF; single-chain proteins with 2 to 16 elements. |

Frozen inputs beyond the panel: `data/mvscore/chem_comp.json` (component names and
synonyms, RCSB) and `data/mvscore/uniprot_sites.json` (UniProt active-site features),
both with source and retrieval date. Catalytic residues are asked for only where UniProt
lists two or more active-site positions and every one of them is observed in the
structure with the amino acid UniProt has (so the S195A factor IXa of 8EPH and 3KCG is
not used).

`provenance.difficulty` records per task: `needs_ligand_identity` (a compound or
modification is named in words), `needs_structure_lookup` (the residues are not named in
the prompt), `needs_uniprot_mapping` (never in this tier: answers use author numbering),
and the three numbering flags of the residues the answer selects.

Replaces the eight earlier grounded tasks; their two requests (the named ligand, the
disulfide cysteines) are templates `gr-ligand` and `gr-disulfides` here.
