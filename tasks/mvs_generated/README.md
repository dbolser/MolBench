needs is in the request: the entry, chains and residue numbers (author numbering),
representation and colour. The reference holds what the prompt states and nothing else
(FINAL_PLAN decision 17), and every value in it is read from the frozen facts and atom
table of the entry.

## How each reference is derived

| template | reference |
|---|---|
| `tr-cartoon` | Mol*'s `polymer` selection (frozen atom table). |
| `tr-chain-colour` | Author chain id from the facts; one grey cartoon recoloured on it. |
| `tr-chain-only` | Author chain id from the facts; a cartoon of that chain only. |
| `tr-chains-named` | Every polymer chain of the facts (3 to 6), one cartoon each, in the colour the prompt gives. |
| `tr-colour-by-chain` | `polymer` cartoon with the chain-id colour theme (3 or more chains); the grader accepts any one-colour-per-chain answer. |
| `tr-glycans` | All sugar atoms (`branched` minus polymer), by label chain; Mol*'s `branched` (sugars plus the residues they are bonded to) is accepted too. |
| `tr-het-code` | Every residue with the component code named in the prompt (facts). |
| `tr-ions` | Mol*'s `ion` selection, only where it equals the entry's single-atom ions (this is what excludes 1HHO, whose only "ion" is a phosphate). |
| `tr-ligands` | Mol*'s `ligand` selection, only where it equals the entry's non-polymer, non-water, non-sugar atoms. Where those are only crystallisation additives (glycerol, DMSO) the prompt says "small molecule"; an entry with a ligand and additives is not used. |
| `tr-nucleic` | Mol*'s `nucleic` (and `protein`) selection, checked to be exactly the DNA or RNA chains of the facts. Built by the grounded generator's template on that tier's choice of structures; it needs no lookup, so it is here. |
| `tr-range-labels` | Two such runs, each recoloured on one grey cartoon and carrying a text label; the label text is in the prompt (neutral names from a fixed list). |
| `tr-range-rows` | Two or three such runs, each recoloured on one grey cartoon. |
| `tr-range-sticks` | A run of 5 to 12 consecutive author-numbered residues from the atom table (no insertion code; polymer atoms only). |
| `tr-rep-word` | `polymer` in the representation the prompt's word means (wireframe = `line`, space-filling / CPK = `spacefill`, backbone trace = `backbone`). |
| `tr-residue-focus` | One author-numbered residue from the atom table, as ball-and-stick, with a camera focus on it. |
| `tr-strands` | The two DNA chains of the facts, one cartoon each. |
| `tr-surface` | `polymer`, on entries whose only polymer is protein. |
| `tr-water` | Mol*'s `water` selection. |

Each task records under `provenance.difficulty` whether the residues it selects have an
author number different from the label (SEQRES) number, an author chain id different
from the label chain id, or an insertion code. Each prompt is one of three wordings of
its template, chosen by seed. Colours come from the 19-colour task palette.

Replaces the 36 tasks of the old 7 x 6 grid and the five hand-written tasks of
`tasks/mvs/` (their requests live on as templates here or in the grounded tier).
